      송폼
      {C(목소리)} → 빨간색, 괄호 안은 작게. B*6은 그대로.
      악보 넣기
      이미지·PDF를 클릭·드래그·Ctrl+V. PDF가 가장 선명합니다.
      자르기 · 크기 ✂
      썸네일을 누르면 위·아래 잘라내기와 크기 조절. 인쇄 폭 100%가 되면 꽉 찹니다.
      키 바꾸기 ♯
      썸네일 → ♯ → 코드 찾기 → 적용. 원래 키를 먼저 확인하세요. 노랑은 확인 필요, 빨강은 못 읽음 — 눌러서 고칩니다.
      두 곡 한 장
      곡 카드의 앞 곡과 같은 페이지에 넣기. 악보가 여러 장이면 자르기 패널의 앞 장과 같은 페이지에 넣기. 폭이 모자라면 양쪽을 더 잘라내세요.
      악보 보관함
      넣은 악보가 제목 - 키로 자동 저장됩니다. 다음엔 ＋ 보관함에서 악보 넣기로 꺼내 씁니다. 악보와 송폼은 따로 가져옵니다(송폼 N ▾). 그림을 누르면 미리보기.
      송폼 기록
      콘티 이름을 정할 때·인쇄할 때·새 콘티로 넘어갈 때만 남습니다. 악보마다 최근 3개.
      단축키
      Ctrl+Z 되돌리기 · Ctrl+Shift+Z 다시 실행. 곡 카드의 ▾ 접기, ⧉ 복제. 미리보기 위 ‹ › 쪽 넘기기.
      보관·PDF
      고칠 때마다 이 브라우저에만 자동 저장됩니다. PC와 폰은 각각 따로예요. 인쇄 창에서 "PDF로 저장"을 고르면 PDF가 됩니다.
      보관함 옮기기
      악보 보관함의 내보내기로 파일 하나를 받아, 다른 기기에서 가져오기로 넣습니다. 백업으로도 쓰세요.
